# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

In short: be respectful and constructive. Harassment and personal attacks are not
tolerated. Focus on the work.

To report a Code of Conduct concern, use GitHub's private vulnerability reporting
on this repository, or contact the maintainer privately. Reports are handled
confidentially.
